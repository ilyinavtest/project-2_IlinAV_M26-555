## Управление таблицами

### Доступные команды:
- `create_table <имя> <колонка1:тип> <колонка2:тип> ...` — создать таблицу.
- `list_tables` — показать список всех таблиц.
- `drop_table <имя>` — удалить таблицу.
- `help` — показать справку.
- `exit` — выйти из программы.

### Поддерживаемые типы данных:
`int`, `str`, `bool`.

### Пример использования:


>>> database
***Процесс работы с таблицей***
Функции:
<command> create_table <имя_таблицы> <столбец1:тип> ... - создать таблицу
...
>>>Введите команду: create_table users name:str age:int
Таблица "users" успешно создана со столбцами:
  - ID: int
  - name: str
  - age: int

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.

>>>Введите команду: exit

## CRUD-операции с данными

После создания таблицы вы можете добавлять, читать, обновлять и удалять записи.

### Команды:
- `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — добавить запись.
- `select from <имя_таблицы> [where <столбец> = <значение>]` — прочитать записи (все или с фильтром).
- `update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>` — обновить записи.
- `delete from <имя_таблицы> where <столбец> = <значение>` — удалить записи.
- `info <имя_таблицы>` — показать структуру и количество записей в таблице.

### Важное правило парсинга:
Строковые значения **обязательно** должны быть в кавычках (например, `"Sergei"`). Числа и булевы значения (`true`/`false`) пишутся без кавычек.

### Пример использования:

>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

>>>Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+

>>>Введите команду: delete from users where ID = 1
Успешно удалено записей: 1.
